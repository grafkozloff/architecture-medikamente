## **Реестр средств защиты данных**

| **Данные**                                                                           | **В чем необходимость**                                         | **Инструменты защиты**                                                                                                                                                                                                                     |
|--------------------------------------------------------------------------------------|-----------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Персональные данные (PII)**  <br>(ФИО, контакты, паспортные данные)                | Защита от утечек, соблюдение 152-ФЗ, контроль доступа           | • **At Rest:** Шифрование дисков (например, BitLocker)  <br>• **In Transit:** TLS для API, VPN для удалённого доступа  <br>• **Контроль:** Контроль утечек в Symantec DLP, Мониторинг в Splunk, Azure AIP для тегирования, RBAC в Keycloak |
| **Медицинские данные (PHI)**  <br>(медицинские карты, результаты анализов, диагнозы) | Конфиденциальность, целостность, разграничение доступа по ролям | • **At Rest:** Шифрование дисков (например, BitLocker)  <br>• **In Transit:** TLS для API, VPN для удалённого доступа  <br>• **Контроль:** Контроль утечек в Symantec DLP, Мониторинг в Splunk, Azure AIP для тегирования, RBAC в Keycloak |
| **Финансовые данные**  <br>(платежи, данные 1С, отчёты)                              | Защита от мошенничества, соответствие законодательству          | • **At Rest:** Шифрование дисков (например, BitLocker)  <br>• **In Transit:** TLS для API  <br>• **Контроль:** Контроль утечек в Symantec DLP, Мониторинг в Splunk, Azure AIP для тегирования, RBAC в Keycloak                             |
| **Данные аутентификации**  <br>(учётные записи, токены, роли)                        | Защита от несанкционированного доступа                          | • **At Rest:** Шифрование дисков (например, BitLocker)  <br>• **In Transit:** TLS для LDAPS (Active Directory), OAuth2  <br>• **Контроль:** Мониторинг в Splunk                                                                            |
| **Данные интеграций**  <br>(лаборатория, ККМ, партнёры)                              | Защита от MITM-атак, целостность данных                         | • **At Rest:** Шифрование дисков (например, BitLocker)  <br>• **In Transit:** TLS для API  <br>• **Контроль:** шифрование конвейеров Apache NiFi, мониторинг в Splunk                                                                      |
| **Аналитические данные**  <br>(Data Lake, Data Marts)                                | Обезличивание, защита от утечек при аналитике                   | • **At Rest:** Шифрование дисков, шифрование в S3  <br>• **In Transit:** TLS для NiFi и отчётов  <br>• **Контроль:** Azure AIP для тегирования, маскирование в ClickHouse                                                                  |
| **Резервные копии**                                                                  | Защита от потери и несанкционированного доступа                 | • **At Rest:** Шифрование дисков, Шифрование бэкапов (например, Veeam Backup & Replication)  <br>• **In Transit:** TLS при передаче  <br>• **Контроль:** Мониторинг в Splunk                                                               |
