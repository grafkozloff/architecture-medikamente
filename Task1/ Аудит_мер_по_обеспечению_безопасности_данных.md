## Список проблемных зон
### Критический риск
1.  **Незащищенное хранение PII и PHI**
    *   Excel файлы с персональными данными доступны всем сотрудникам
    *   Нет шифрования на уровне хранения
    *   Отсутствует контроль доступа к файлам
2.  **Отсутствие сегментации медицинских данных (PHI)**
    *   Все медицинские карты в общем доступе
    *   Нет разграничения между отделами
    *   Возможность доступа врачей к данным всех пациентов
3.  **Небезопасная передача данных**
    *   Лабораторные результаты передаются без шифрования
    *   Интеграция ККМ-1С через незащищенный OLE
    *   Отсутствует защита от MITM-атак
### Высокий риск
4.  **Отсутствие аудита действий**
    *   Нет журналирования доступа к данным пациентов
    *   Не отслеживаются изменения в медицинских записях
    *   Нет мониторинга подозрительной активности
5.  **Нарушение принципа минимальности данных**
    *   Собираются избыточные персональные данные
    *   Хранение данных дольше необходимого срока
    *   Отсутствие политик удаления устаревших данных
6.  **Слабые механизмы аутентификации**
    *   Общие учетные записи для доступа к файлам
    *   Нет многофакторной аутентификации
    *   Устаревшие парольные политики
### Средний риск
7.  **Отсутствие резервного копирования**
    *   Нет защищенных бэкапов медицинских данных
    *   Риск потери данных при сбое оборудования
    *   Непротестированный процесс восстановления
8.  **Несоответствие законодательству**
    *   Нарушение 152-ФЗ о персональных данных
    *   Отсутствие политики обработки ПДн
    *   Нет назначенного ответственного за защиту ПДн
9.  **Уязвимости в бизнес-процессах**
    *   Двойной учет создает расхождения данных
    *   Ручные процессы подвержены человеческим ошибкам
    *   Отсутствие валидации вводимых данных

## **Улучшения безопасности данных для состояния AS-IS**
### **Список данных для защиты и способы защиты:**
*   **Персональные данные в Excel:**
    *   Шифрование трафика (Data in Transit)
    *   Шифрование дисков (Data at Rest)
    *   Маскирование в отчетах
    *   Обезличивание для аналитики и разработки
*   **Медицинские данные в JPG/PDF:**
    *   Шифрование трафика (Data in Transit)
    *   Шифрование дисков (Data at Rest)
    *   Обезличивание для аналитики и разработки
*   **Финансовые данные в Excel и 1С:**
    *   Шифрование трафика (Data in Transit)
    *   Шифрование дисков (Data at Rest)
    *   Маскирование в отчетах
    *   Обезличивание для аналитики и разработки

### Механизм тегирования данных
*   **Инструменты:** В качестве инструмента для автоматического и ручного тегирования предлагается использовать Microsoft Azure Information Protection (AIP).
*   **Система тегирования:**
    *   Классификация уровня конфиденциальности: "К4_ОБЩ", "К3_ОПЕР", "К2_ПДн", "К2_МЕД", "К1_МЕД" и т.д.
    *   Data Lineage: "SOURCE_Пациент", "SOURCE_Лаборатория", "SOURCE_Врач", "SOURCE_Аналитика" и т.д.
    *   Разграничение доступа (через Windows Dynamic Access Control и Active Directory): "ACCESS_Врачи", "ACCESS_Ресепшен", "ACCESS_Бухгалтерия" и т.д.

### Список инструментов безопасности
*   **Microsoft Azure Information Protection (AIP)**
    *   Автоматическое тегирование Excel, PDF, JPG
    *   Шифрование конфиденциальных файлов
    *   Интеграция с Active Directory для контроля доступа
*   **Azure Active Directory Premium**
    *   Многофакторная аутентификация для всех сотрудников
    *   Условный доступ (блокировка вне рабочей сети)
    *   Интеграция с AIP
*   **BitLocker**
    *   Полное шифрование файловых серверов
    *   Защита данных при физическом доступе
*   **Windows Dynamic Access Control**
    *   Автоматическое применение прав на основе тегов AIP
    *   Контроль доступа к папкам пациентов
*   **Splunk Enterprise Security**
    *   Централизованный мониторинг нарушений
    *   Обнаружение аномального доступа
*   **Symantec DLP Basic**
    *   Блокировка копирования на USB
    *   Контроль отправки email с конфиденциальными данными
